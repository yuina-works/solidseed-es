＃HTML・CSS制作とChatGPT活用の内容まとめ

＃＃内容

HTML/CSSを用いたWebページの制作と、ChatGPTを活用したエラー解消・学習の効率化

＃＃きっかけ

Webサイトの仕組みに興味を持ち、実際に自分の手でコードを書いてページを作ってみたいと思ったことがきっかけです。

＃＃どこまで試したか

教材のサンプルコードを参考にしながら、HTMLとCSSを用いた基本的なWebページのレイアウト作成に取り組みました。コードを書いていく中で表示崩れなどのエラーが発生した際には、ChatGPTを活用してコードの意味や原因を調べました。AIの回答をただ写すのではなく、自分でも記述内容を確認しながら原因を考え、試行錯誤しながら解決策を探りました。
＃＃効果・学び
エラー解決にかかる時間が短縮され、スムーズに学習を進められるようになりました。この経験を通じて、分からないことに直面した際、自分で情報を集めて原因を考えながら解決策を探る大切さを学びました。今後もAIなどのツールを適切に活用しながら、自ら学び、ITの知識や技術を深めていきたいと考えています。
